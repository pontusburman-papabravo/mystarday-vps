Hygienschema för barn — PDF

Hygienrutiner innehåller många delsteg som vuxna tar för givna. Ett hygienschema bryter ner tvätta händer, borsta tänder och duscha i tydliga bilder — särskilt hjälpsamt för barn med NPF eller motoriska utmaningar.

Vanliga hygiensteg att visualisera

Tvätta händer: vatten på, tvål, gnugga, skölj, torka. Borsta tänder: tandkräm, borsta upp och ner, spotta, skölj. Duscha: klä av, vatten, schampo, skölj, torka, klä på. Varje kedja kan bli ett eget mini-schema eller ingå i morgon- och kvällsrutinen.

Barn som glömmer ordningen eller hoppar över steg mår ofta bättre med ett schema i badrummet än med muntliga påminnelser som känns som tjat.

Tips för badrum och förskola

Laminera schemat eller sätt det i en genomskinlig ficka så det tål fukt. Använd bilder barnet känner igen — gärna foton från ert eget badrum. I förskolan kan ett gemensamt hygienschema vid handfatet påminna hela gruppen.

Var specifik: "torka händer" som eget steg efter "skölj" minskar att barnet springer iväg med våta händer.

  • Dela upp tvätta händer i fem tydliga steg
  • Placera vid handfatet eller spegeln
  • Laminera eller använd genomskinlig ficka

Ladda ner hygienschema

Vår hygienschema-PDF finns som tom mall och färdigt exempel, plus lösa bildkort att klippa ut. Kombinera gärna med morgon- eller kvällsschema om hygien ingår där.

Stavningen är medveten: hygienschema (inte "hygiensschema") — samma ord vi använder i hela resursbiblioteket för konsekvens.

Sensoriska anpassningar

Barn som ogillar vatten i ansiktet kan behöva färre steg synliga under dusch och tydligare "klar"-signal. Barn som hyperfokuserar på tvätt kan behöva timer så steget inte tar tjugo minuter.

Anpassa ordningen: vissa barn borstar tänder före pyjamas, andra efter. Schemat ska spegla er verklighet — inte en generisk idealordning från en blogg.

Om ett hygiensteg alltid misslyckas, dela upp det: istället för "borsta tänder" kan ni ha tandkräm på, borsta upp, borsta ner, spotta, skölj. Fler små steg ger fler möjligheter att lyckas och bocka av.
