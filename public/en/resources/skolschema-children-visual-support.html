Skolschema med bildstöd

Skoldagen har många byten: lektion, rast, matsal, läxa, idrott. Ett skolschema med bildstöd gör dagens struktur synlig — särskilt för barn som behöver förberedelse inför varje moment.

Vad ingår i ett skolschema?

Ankomst, första lektion, rast, lunch, eftermiddagsaktivitet, läxa, hämtning. Anpassa efter barnets ålder — yngre barn behöver färre detaljer, äldre kan ha plats för varje lektion om det minskar ångest.

Lägg till "vad ska med i väskan" som kvällssteg hemma snarare än på morgonens skolschema — annars blir listan för lång.

Hem och skola

Sätt schemat där barnet ser det på morgonen — eller i väskan som ett laminerat kort. Lärare och specialpedagog kan använda samma bilder i klassrummet för konsekvens.

För läxor: ett kort "först läxa, sedan lek" vid skrivbordet räcker ofta. Skolschemat handlar om dagens överblick, inte varje enskild uppgift.

  • Färre steg för yngre barn
  • Packlista som kvällssteg hemma
  • Dela bildspråk med skolan om möjligt

Läxor och struktur

Skolschemat visar dagens bågar — läxor behöver ofta ett separat först–sedan-kort vid skrivbordet. Att klumpa ihop hela skoldagen på ett kort blir för tät information.

Vid läxor: först material fram, sedan en uppgift i taget, sedan paus. Synlig kedja minskar att barnet sitter och stirrar utan att börja.

Fråga läraren vilka aktiviteter som alltid sker samma dag — idrott på onsdag, bibliotek på fredag — och markera dem tydligt på veckoöversikten om barnet behöver se hela veckan.

  • Läxor = separat först–sedan vid skrivbordet
  • Skoldag = överblick, inte varje uppgift
  • Markera fasta aktiviteter som idrott på samma dag varje vecka
  • Dela samma bilder med läraren om möjligt
