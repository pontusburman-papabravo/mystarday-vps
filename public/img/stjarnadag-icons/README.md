# Stjärndag High Contrast Icons v3

65 nya SVG-ikoner anpassade för den mörka mobilvyn.

## Stil
- Nästan vita symboler
- Tjockare linjer
- Minimal skugga
- Ingen neon-glow
- Transparent bakgrund
- Liten guldig Stjärndag-signatur

## Storlekar
- Bottennavigation: 30–32 px
- Toppikoner: 28–30 px
- Snabbåtgärder: 40–44 px

## Cursor
Packa upp under `public/assets/icons/stjarnadag-v3`.
Läs `manifest.json` och ersätt nuvarande föräldra-, navigations- och systemikoner.
Behåll barnets temabaserade ikoner där de redan finns.
Använd `child-fallback` endast där temat saknar ikon.
Ta bort vita ikonrutor och extra CSS-glow.
