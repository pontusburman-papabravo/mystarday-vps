# Stjärndag Quick Actions v4

Ersätter de fyra stora v3-ikonerna i snabbvalskorten:

- I efterhand
- Engångs-aktivitet
- Extra stjärnor
- Ledig dag

## Designändringar
- Ingen kritvit glow
- Inga dekorativa gula statusprickar
- Samma 32×32-grid som navigation v4
- Samma linjetjocklek och optiska vikt
- Dämpad salvia för sekundära detaljer
- Guld används endast i aktivt eller belöningsrelaterat läge

## Rekommenderad användning
Visa SVG:n i 48–56 px i korten. Behåll minst 16 px luft runt ikonen.

- Standard på mörkt kort: `svg/dark/`
- Markerat/aktivt kort: `svg/dark-active/`
- Ljust tema: `svg/light/`

Skuggor ska ligga på kortet, inte på SVG-ikonen.
