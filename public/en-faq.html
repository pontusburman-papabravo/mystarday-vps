Installation

My Starday is a web app (PWA) you install from the browser. On iPhone: open in Safari → Share → Add to Home Screen. On Android: Chrome shows an install prompt automatically.
Yes! My Starday is in the App Store for iPhone. Download here. You can also use it in the browser as a PWA.
Yes! It works on all modern browsers — iPhone, Android and desktop.
