# Stjärndag — Promotional Film Pipeline

Isolated Node 20+ pipeline for three promotional films. Uses **Pika via fal.ai** for scene generation and **ffmpeg** for post-process editing (captions, logo, audio, multi-format export).

**This package is not part of the main app `build`, deploy, or `test:gate`.**

## Prerequisites

- Node.js 20+
- ffmpeg + ffprobe on `PATH`
- fal.ai account and API key ([dashboard](https://fal.ai/dashboard/keys))

## Setup

```bash
cd video-production  # pragma: allowlist secret
cp .env.example .env
# Edit .env and set FAL_KEY=...

npm install
```

Replace placeholder assets before paid generation:

| Asset | Path |
|-------|------|
| Logo (PNG, transparent) | `assets/logo/brand-logo.png` |
| Family reference stills | `assets/references/*.png` |
| Licensed music / ambient | `audio/*.mp3` |

Generate reference stills for testing:

```bash
npm run test:placeholders
```

## Film manifests

| ID | Title | Scenes |
|----|-------|--------|
| `a-morning-without-nagging` | A Morning Without Nagging | 5 × 5s |
| `tomorrow-starts-here` | Tomorrow Starts Here | 5 × 5s |
| `real-families` | Real Families | 5 × 5s |

Manifests live in `manifests/*.json`. See **`manifests/CREATIVE-BRIEF.md`** — arc is **Kärlek → Kaos → Hopp → Lösning**; sell the family identity, not the app.

Each scene defines:

- English Pika prompt (no readable UI; phone scenes use extreme blur)
- `role`: recognition | chaos | hope | payoff | validation | story | app-glimpse | brand
- Swedish caption (empty for hook/app-glimpse; use `\n` for manual line breaks)
- `audioCues` — sound-design notes for post (VO, SFX, silence)
- `skipPika: true` on black breath scenes (no API cost)
- `validationScene: true` on the shoes scene — iterate on Pika before full generation
- `duckMusic: true` on validation/payoff shoes beats — score out, zipper SFX carries the moment
- `taglineVariantDefault: "E"` — logo-only ending; test A–D with `--tagline B` at render

## Commands (from repo root)

```bash
npm run video:dry-run          # Plan API calls + cost estimate
npm run video:generate         # Submit scenes to Pika (requires --confirm)
npm run video:render           # ffmpeg editing + export
npm run video:all              # generate + render
```

### Compare ending taglines (placeholder render)

```bash
npm run video:render -- --film a-morning-without-nagging --placeholders --tagline B
```

Omit `--tagline` for variant **E** (door → silence → logo only).

### Validate visual style with one scene (~$0.35)

The **shoes scene** — child puts on shoes, looks up, parent smiles, child smiles back:

```bash
npm run video:dry-run -- --film a-morning-without-nagging --scene scene-05-shoes-alone
npm run video:generate -- --film a-morning-without-nagging --scene scene-05-shoes-alone --confirm
```

Iterate until it feels äkta. No stars, no UI, no logo in Pika — only human moments.

From this package directory:

```bash
npm run dry-run
npm run generate -- --confirm
npm run generate -- --placeholders   # Local color clips, no API cost
npm run render -- --placeholders
npm run test:placeholders              # Full pipeline smoke test
```

### Single film

```bash
npm run video:generate -- --film a-morning-without-nagging --confirm
```

## Cost safeguards

- **`--confirm` required** before any billable Pika submission
- **`MAX_GENERATIONS_PER_RUN`** — default 12 scenes per invocation
- **`MAX_GENERATIONS_PER_DAY`** — default 24 scenes per calendar day (tracked in `state/`)
- **Dry-run** prints pending API calls and estimated USD before you commit
- **Resume** — `state/<film-id>.json` stores job IDs; completed scenes are skipped

## Outputs

Per film, three masters in `output/<basename>/`:

- `*-landscape.mp4` — 1920×1080
- `*-vertical.mp4` — 1080×1920
- `*-square.mp4` — 1080×1080

Raw Pika downloads: `raw/<film-id>/` (gitignored).

## Pipeline stages

1. **Generate** — image-to-video via `fal-ai/pika/v2.2/image-to-video`, shared reference image per family
2. **Normalize** — scale/pad to 1920×1080, 30 fps, H.264
3. **Captions** — Swedish `drawtext` overlay per scene
4. **Transitions** — ffmpeg `xfade` between scenes
5. **Logo** — bottom-right overlay (not generated by Pika)
6. **Audio** — music + ambient mix with fades
7. **Export** — crop to landscape / vertical / square

## What not to commit

See `.gitignore`: API keys, `raw/`, `output/`, licensed audio, and local `.env`.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| `FAL_KEY is not set` | Copy `.env.example` → `.env` |
| `Billable generation blocked` | Add `--confirm` or use `--placeholders` |
| `Reference image missing` | Add PNG under `assets/references/` |
| `Daily limit would be exceeded` | Wait until next day or raise `MAX_GENERATIONS_PER_DAY` |
| Missing DejaVu font | Install `fonts-dejavu-core` (Linux) or adjust font path in `lib/ffmpeg.mjs` |
