# 00A — Experience Manifesto

**Authority:** How the product must feel — subordinate to Constitution only

---

## Child feeling

> *"Det här är min värld."*

Welcome home, not software. The child is capable. The app is a companion, not a manager.

| Moment | Target feeling |
|--------|----------------|
| Open Idag | "I know what's next" |
| Complete activity | Pride before points |
| Enter Min värld | Ownership — "this grew because I did things" |
| Familj | Belonging — caregivers visible, never compared |

---

## Parent feeling

> *"Det här hjälper oss."*

Relief, one next step, trust. Never another dashboard to manage.

| Moment | Target feeling |
|--------|----------------|
| Morning open Hem | Calm — one obvious action |
| After child completes | "It worked without me nagging" |
| After setup | "We're set up" not "now configure everything" |
| Error or delay | Honest, fixable — no surprise blame |

---

## Morning stress test (EM-06)

At 07:15, one hand, portrait, child late:

1. Can parent see **one** next step in 5 seconds?
2. Can child see **one** primary action without reading?
3. Does anything block exit to school?
4. Would Nintendo respect this child player?
5. Would a stressed parent feel calmer?

Fail any → redesign before ship.

---

## Anti-feelings (forbidden)

- Surveillance · guilt · casino · enterprise sludge · generic toy UI · nagging machine

---

## Three child places (canonical)

| Place | Role |
|-------|------|
| **Idag** | Routine — action layer |
| **Min värld** | Reward — meaning layer (includes Skattkammaren as star bridge, not a fourth root) |
| **Familj** | Belonging — relation layer |

Skattkammaren is a **surface inside the reward loop**, not a peer world to Idag/Min värld/Familj. See ADR in `14_DECISION_LOG.md` (child-ia-2026-07-02).
