DEL 1 — KONVERTERING (5 min)
-----------------------------
1. Mål (trofé) → Konverteringar → + Skapa konverteringsåtgärd
2. Webbplats → Sign-up → GA4-property (ID i Analytics Admin) ELLER manuell tagg
3. Om GA4 visar "No events yet":
   - Inkognito → [DOMAIN]/register → godkänn ANALYS → skapa testkonto
   - GA4 → Realtime → bekräfta sign_up
   - GA4 Admin → Key events → lägg till sign_up
4. Mål → Konverteringar → Inställningar:
   - Sign-up = PRIMÄR
   - Page view = SEKUNDÄR eller INAKTIV (viktigt!)

DEL 2 — PMAX (Campaign #1) (2 min)
-----------------------------------
1. Kampanjer → Campaign #1 → Inställningar → Budget
   - Sänk till 30–50 kr/dag (eller Pausa tills Sign-up har data)
2. Kampanj → Söktermer → markera irrelevanta → Lägg till som negativt
