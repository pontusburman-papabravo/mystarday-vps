# Källbilder — Instagram recensioner

Lägg **dina 6 originalbilder** (från chatten/skärmdumparna) i denna mapp med exakt dessa filnamn:

| Fil | Innehåll (din bild) |
|-----|---------------------|
| `01-recensioner.png` | Föräldrarrecensioner (guld rubrik) |
| `02-fardiga-scheman.png` | Färdiga scheman & belöningar |
| `03-landing.png` | Landningssidan "Förenkla vardagen" |
| `04-hem.png` | *(används ej i videon — valfri)* |
| `05-schema-anna.png` | PDF/schema-vy för Anna |
| `06-rutiner.png` | För dig — Trygga kvällar / Bra morgnar |

`.jpg` / `.jpeg` / `.webp` fungerar också (samma basnamn).

## Generera video

```bash
npm run instagram:recensioner
```

Output: `../instagram-recensioner.mp4` (12 sek, hooks på skärmen).
