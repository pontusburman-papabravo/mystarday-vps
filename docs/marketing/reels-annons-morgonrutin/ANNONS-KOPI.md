# Reels-annons — Morgonrutin utan tjat

**Format:** 9:16 vertikal video, 15–30 sek, med ljud  
**Mål:** Registrering på mystarday.se  
**Kampanj:** Meta (Instagram Reels / Facebook Reels)

---

## Primär annonstext (Meta Ads)

**Variant A — problem → lösning**

> Morgonrutinen fastnar i tandborstning, kläder och "kom igen nu"?  
>  
> Min Stjärndag ger barnet ett visuellt schema steg för steg — med stjärnor som belöning.  
>  
> Du bygger rutinen. Barnet följer sin egen vy. Mindre tjat, mer lugn.  
>  
> Gratis för grundarmedlemmar. Prova idag.

**Variant B — kort & punchig**

> Sluta upprepa "borsta tänderna" fem gånger.  
> Ge barnet ett bildschema de faktiskt följer — och stjärnor som motiverar.  
> Min Stjärndag. Gratis att börja.

**Variant C — NPF-vinkel (målgrupp)**

> Barn som behöver tydliga steg mår bättre av visuella rutiner.  
> Min Stjärndag: schema med bilder, steg-för-steg, stjärnbelöningar.  
> Passar ADHD, autism och alla som vill ha en lugnare morgon.

## Produktionstips (Reels)

- **Upplösning:** 1080 × 1920 px (9:16)
- **Ljud:** Ja — Reels med ljud presterar bättre (röst + lätt bakgrundsmusik)
- **Text på skärm:** Stora rubriker, max 5–7 ord per rad (många tittar utan ljud först)
- **Säker zon:** Håll viktig text mitt i bilden — undvik topp/botten där UI täcker
- **Captions:** Bränn in undertexter (svenska) för tittare utan ljud
