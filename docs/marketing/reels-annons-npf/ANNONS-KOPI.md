# Reels-annons — Bildstöd & NPF

**Format:** 9:16 vertikal video, 15–30 sek, med ljud  
**Målgrupp:** Föräldrar till barn med ADHD, autism eller behov av visuellt bildstöd

---

## Primär annonstext

> Barn som behöver tydliga steg mår bättre av visuella rutiner.  
>  
> Min Stjärndag: schema med bilder, NU/NÄSTA-markeringar och stjärnbelöningar.  
>  
> Mindre stress vid övergångar. Mer förutsägbarhet. Positiv förstärkning.  
>  
> Gratis för grundarmedlemmar · mystarday.se

## Rubrik

- `Bildstöd i vardagen`
- `Visuellt schema för NPF-barn`
- `Tydliga steg, mindre stress`

## Meta-målgrupp (intressen)

- ADHD
- Autism
- Specialpedagogik
- Bildstöd / TEACCH
- Föräldraskap

## Videoscript (30 sek)

| Tid | Röst |
|-----|------|
| 0:00–0:03 | *"Barn som behöver tydliga steg — vad händer nu? Vad kommer sen? Övergångar kan vara det svåraste."* |
| 0:03–0:06 | *"Visuellt bildstöd gör skillnad."* |
| 0:06–0:12 | *"Min Stjärndag visar schemat med bilder — NU och NÄSTA — så barnet alltid vet var de är i rutinen."* |
| 0:12–0:18 | *"Varje klart steg ger en stjärna. Positiv förstärkning som faktiskt funkar."* |
| 0:18–0:24 | *"Stjärnorna samlas mot belöningar ni själva väljer."* |
| 0:24–0:30 | *"Min Stjärndag. Gratis att börja."* |
