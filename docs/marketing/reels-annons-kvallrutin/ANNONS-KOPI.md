# Reels-annons — Kvällsrutin utan tjat

**Format:** 9:16 vertikal video, 15–30 sek, med ljud  
**Mål:** Registrering på mystarday.se

---

## Primär annonstext

> Läggdags blir en kamp varje kväll?  
>  
> Min Stjärndag visar barnet kvällsrutinen steg för steg — dusch, pyjamas, tandborstning, saga.  
>  
> Tydliga bilder. Stjärnor som belöning. En lugnare kväll för hela familjen.  
>  
> Gratis att börja på mystarday.se

## Rubrik

- `Kvällsrutin utan tjat`
- `Läggdags med bildschema`
- `Lugnare kvällar hemma`

## Videoscript (30 sek)

| Tid | Röst |
|-----|------|
| 0:00–0:03 | *"Känner du igen det? Dusch. Pyjamas. Tandborstning. Och 'det är läggdags nu' — om och om igen."* |
| 0:03–0:06 | *"Det finns ett enklare sätt."* |
| 0:06–0:12 | *"Min Stjärndag visar barnet exakt vad som händer nu — och vad som kommer sen i kvällsrutinen."* |
| 0:12–0:18 | *"Varje klart steg ger en stjärna. Motivation som faktiskt funkar."* |
| 0:18–0:24 | *"Stjärnorna samlas mot belöningar ni själva väljer — som extra sagostund."* |
| 0:24–0:30 | *"Min Stjärndag. Gratis att börja."* |
