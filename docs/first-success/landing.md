# Landningssida — First Success (eget spår)

Landningen ska berätta **samma historia** som dag 0 i appen — men är ett **eget projekt** (copy, SEO, konvertering). Den lever här, inte i kärn-specen.

Se [FIRST-SUCCESS.md](../FIRST-SUCCESS.md) för produktlagar.

---

## Problem idag

Landningen säger "Bygg rutiner." Föräldern köpte "Hjälp mig få morgonen att fungera."

De försöker förklara hela produkten innan användaren upplevt den.

---

## Löfte (synkat med app)

| ❌ | ✅ |
|----|-----|
| Bygg rutiner | Ikväll kan ditt barn följa sin första rutin |
| Du bygger, planerar | Ditt barn ser vad som händer nu |
| Tre steg: bygg → följ → stjärnor | Barnet följer → det fungerar → du anpassar senare |

**Hero-rubrik (förslag):**  
*Ikväll kan ditt barn följa sin första morgonrutin.*

**Underrubrik:**  
*Kom igång på mindre än två minuter. Inga mallar att välja.*

**CTA:** Skapa konto gratis

---

## "Så fungerar det" — vänd ordningen

1. Barnet följer ett färdigt schema (NU / NÄSTA / SENARE)  
2. Det fungerar (citat från riktiga familjer)  
3. Du anpassar när du vill  

---

## Hjälte = barnet, inte föräldern

| ❌ | ✅ |
|----|-----|
| Du bygger, planerar, delar | Ditt barn ser vad som händer nu |
| | Ditt barn vet vad som kommer sedan |
| | Ditt barn klarar fler saker själv |

---

## Vad som ska upp / ner

**Upp:** barnvy-demo, citat, problem (morgonen fastnar), CTA, "kom igång på 2 min"

**Ner / egna sidor:** veckoschema, push, pedagog, paket, grundarprogram (kort nämn OK)

---

## Framtid (ej v1)

Coach kan senare personalisera landning för återbesökare (baserat på Brain facts) — inte i första implementationen. Brain läser inte landning; landning läser inte experiment direkt från Brain.
