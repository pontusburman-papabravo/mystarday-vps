# Context Contract

Read the **minimum relevant context** for the assignment.

## Avoid by default

- Entire repo
- Full git history
- All product docs
- All test files

## Use instead

- Changed-files router (`npm run test:changed`)
- Domain mapping
- Risk class (R0–R3)

Critical/shared path changes may broaden context intentionally.

Goal: lower latency, token use, and context confusion without missing relevant risk.
