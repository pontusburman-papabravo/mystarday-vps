# Evidence Contract

Permanent rule:

```
FACT
or
NOT_VERIFIED
```

## Sources (when access exists)

- Repo, tests, logs, analytics, support tickets
- Production read-only inspection
- Current external primary sources (store policy, API docs)

## Founder observation

```
EVIDENCE_SOURCE: founder_observation
```

Hypotheses are allowed. **Invented evidence is forbidden.**

The agent must not rationalize a hypothesis as fact.
