# Should-We-Do-This-Now Gate

For features / larger behavior changes (not R0 bugfix).

```
CHANGE
RISK
PROBLEM
EVIDENCE
WHY_NOW
SMALLEST_VALUE_SCOPE
MUST
NOT_IN_SCOPE
SUCCESS
STATUS=SCOPE_LOCKED
```

Evidence may be: analytics, support, prod data, founder observation, external evidence, or `NOT_VERIFIED` hypothesis.

Lightweight — no issue bureaucracy for trivial changes.
