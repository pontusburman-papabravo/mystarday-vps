# Independent Review

Implementer's own review is **not** independent review.

## Normal risk

- Automated tests + separate reviewer (fresh agent/model or human) where relevant

## High risk (R3)

- Fresh-agent review of spec + diff + evidence
- Avoid anchoring: do not give the reviewer the implementer's reasoning first when it biases judgment

## Human primarily for

- Business trade-offs
- UX judgment
- Risk acceptance
- Irreversible product decisions

Not for mechanical code review that automation + a fresh agent can do.
